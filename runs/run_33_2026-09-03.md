5. Purged/embargoed validation is appropriate when label intervals overlap. The critical implementation principle is to purge by event/label interval rather than by an arbitrary row count when horizons can vary.

## New hypotheses

### H27 — Fail-closed artifact validation
A prediction artifact containing duplicate decision timestamps must cause validation to fail before any performance metric is computed from the mutated dataset. Deduplication must never be an implicit repair operation.

### H28 — Availability-time joins
Every external feature used in the final model must have an explicit `available_at` timestamp. A feature is eligible at decision time only when `available_at <= decision_time`; publication date alone is insufficient for release-sensitive sources.

### H29 — Family-level null control
The final candidate family must be tested jointly using SPA/Reality Check, while DSR and PBO/CSCV are reported as complementary diagnostics. Passing an individual Sharpe test is not enough after model-family search.

### H30 — Cost decomposition stability
The selected candidate must remain economically viable when commission, half-spread, adverse slippage, and market impact are stressed separately and jointly. A result that survives only aggregate or fee-only costs is not production evidence.
